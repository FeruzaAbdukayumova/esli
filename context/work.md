# Esli - Work Details

## Product
AI-powered spaced repetition flashcard platform (web app + browser extension).

## Features
- AI card generation (topic + PDF)
- SM-2 spaced repetition algorithm
- 14 interface languages
- Community/shared decks (812+ premade cards)
- Browser extension (Chrome, Firefox, Edge, Brave)
- Rich text editor with KaTeX math support
- Guest mode (no account required)
- Excel/CSV import
- Card translations (13 languages, MyMemory API)
- Live support chat + AI assistant

## Monetization
- Freemium: Free / Pro ($5/mo) / Premium ($12/mo)
- Stripe integrated in code but not yet live
- Switching to Paddle for subscriptions
- No revenue yet - target: revenue in 1-2 months
