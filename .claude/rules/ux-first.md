# UX-First Development

- Every change should make the user experience better, not worse
- When building features, think from the user's perspective first
- If something feels messy or unintuitive, flag it
- Prefer clean, modern UI patterns
- Test edge cases and error states - Feruza doesn't enjoy testing, so be thorough when reviewing
- When suggesting changes, note the UX impact
