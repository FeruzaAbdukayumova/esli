# Chrome Web Store Screenshots - Shot List

Chrome requires **1280x800** PNG/JPG (preferred) or 640x400. Upload up to 5.

The first screenshot is the most important - it shows in search results. Make it punchy.

---

## Recommended Setup

- Use Chrome on a Retina/HiDPI display for crisp screenshots
- Open Chrome at exactly 1280x800 (use Chrome DevTools device toolbar set to "Responsive" → 1280x800)
- Or take any size and resize/crop to 1280x800 in Preview/Figma
- Use a clean web page in the background (Wikipedia, a Medium article, MDN docs work well)
- Pick something visually relevant - e.g. a biology Wikipedia page if showing study cards

---

## Captions / Overlay Tips

- Keep overlay text short - 4-7 words max
- Use a semi-transparent black bar at top or bottom for readability
- White text, large bold sans-serif
- Don't cover the actual UI in the screenshot

---

## Tools

- **Built-in macOS:** Cmd+Shift+4 then space, click window
- **Chrome DevTools:** Cmd+Shift+M (device mode), set 1280x800, screenshot via menu
- **Figma:** drag the screenshot in, add overlay text, export at 1280x800
- **Free editor:** Photopea (browser-based Photoshop clone)
