## Root Cause (confirmed today)

The GitHub Actions workflow (`daily-pulse.yml`) runs on schedule every day at 09:00 Tashkent time and **has network access** - but all 4 required secrets are empty strings:

| Secret | Value in runner |
|--------|----------------|
| `AGENT_EMAIL` | *(empty)* |
| `AGENT_PASSWORD` | *(empty)* |
| `TELEGRAM_BOT_TOKEN` | *(empty)* |
| `TELEGRAM_CHAT_ID` | *(empty)* |

The workflow has run and failed every day since at least 2026-04-10. The failure report written by the GH Actions runner never gets committed because the commit step is skipped when the main step exits with code 1.

The Claude Code remote container has a separate issue: its egress proxy blocks `api.esli.app` and `api.telegram.org`, so this agent also cannot fetch data or send Telegram messages directly.

---

## The Fix (one-time, 2 minutes)

Add the 4 secrets to: **GitHub repo → Settings → Secrets and variables → Actions → New repository secret**

| Secret name | Value |
|-------------|-------|
| `AGENT_EMAIL` | `agent@esli.app` |
| `AGENT_PASSWORD` | `EsliAgent2026!Secure` |
| `TELEGRAM_BOT_TOKEN` | *(your bot token)* |
| `TELEGRAM_CHAT_ID` | *(your chat ID)* |

After adding secrets, trigger a manual run: **Actions → Daily Pulse → Run workflow**.

The workflow will then run successfully daily and commit reports automatically.
