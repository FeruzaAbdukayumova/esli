## Root Cause

The Claude Code remote execution environment uses an egress proxy that only allows requests to whitelisted hosts. `api.esli.app` and `api.telegram.org` are not in that allowlist.

This is a network policy issue in the execution environment — not a credentials or configuration problem.

## Fix Options (still open)

**Option A — GitHub Actions cron job**
Run the digest from a GitHub Actions workflow on a schedule. The GH Actions runner has unrestricted outbound HTTPS.

Example `.github/workflows/daily-pulse.yml`:
```yaml
on:
  schedule:
    - cron: '0 4 * * *'  # 09:00 Tashkent (UTC+5)
jobs:
  pulse:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python3 agents/scripts/daily-pulse.py
        env:
          AGENT_EMAIL: ${{ secrets.AGENT_EMAIL }}
          AGENT_PASSWORD: ${{ secrets.AGENT_PASSWORD }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
```
