## Root Cause

The Claude Code remote execution environment uses an egress proxy that only allows requests to whitelisted hosts. `api.esli.app` and `api.telegram.org` are not in that allowlist.

This is not a credentials or configuration problem — the same error occurs before any authentication attempt.

## Fix Options

**Option A — Run from GitHub Actions with network access**
The daily-pulse workflow needs to run in an environment with unrestricted outbound HTTPS, or with `api.esli.app` and `api.telegram.org` explicitly allowed.

Check current network policy at: https://code.claude.com/docs/en/claude-code-on-the-web
