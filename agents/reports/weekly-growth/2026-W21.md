## Root Cause

The Claude Code remote execution environment runs in an isolated cloud container with a
strict egress proxy. All outbound HTTPS requests to external hosts return:

```
HTTP 403 Forbidden
Body: "Host not in allowlist"
```

This affects both:
- `api.esli.app` (the Esli backend API)
- `api.telegram.org` (Telegram Bot API for notifications)

The GitHub Actions workflows (`.github/workflows/weekly-growth.yml` and
`.github/workflows/daily-pulse.yml`) are correctly written and would succeed immediately
on GitHub's runners, which have unrestricted egress. They have never run because the
**four required repository secrets have not been configured**.
