## Fix Required: GitHub Actions Secrets

The fix has been ready since W17. Both workflows exist:
- `.github/workflows/daily-pulse.yml` -- runs Mon-Sun at 09:00 Tashkent
- `.github/workflows/weekly-growth.yml` -- runs every Monday at 09:00 Tashkent (NEW this week)

**Neither runs because the 4 required GitHub repo secrets are missing.**

### One-time setup (~5 minutes)

Go to: `github.com/FeruzaAbdukayumova/esli` > **Settings > Secrets and variables > Actions > New repository secret**

| Secret name | Value |
|-------------|-------|
| `AGENT_EMAIL` | agent@esli.app |
| `AGENT_PASSWORD` | (agent password) |
| `TELEGRAM_BOT_TOKEN` | (bot token) |
| `TELEGRAM_CHAT_ID` | (your chat ID) |

After adding secrets, trigger both manually:
- **Actions > Daily Pulse > Run workflow**
- **Actions > Weekly Growth Report > Run workflow**

GitHub Actions has unrestricted egress. Both will succeed immediately.
