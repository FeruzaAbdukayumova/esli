## Root Cause

The Claude Code remote execution environment blocks outbound HTTPS to non-allowlisted hosts.
The egress proxy returns:

```
HTTP/1.1 403 Forbidden
x-deny-reason: host_not_allowed
```

Blocked hosts confirmed:
- `api.esli.app:443` -- the Esli backend API
- `api.telegram.org:443` -- Telegram Bot API for notifications
