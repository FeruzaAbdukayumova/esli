## Root Cause

HTTPS to external hosts not in the allowlist:

- `api.esli.app` -- Esli backend API (403 Forbidden via proxy tunnel)
- `api.telegram.org` -- Telegram Bot API (403 Forbidden via proxy tunnel)

This is a persistent organization-level network policy, not a transient error or
outage. No retry attempts will succeed until the policy is changed.
